# Archived — Concept A ("sp" monogram)

These are the original approved-then-superseded logo files: a rounded
square with a docking circle at its lower-right corner, paired with an
unmodified "Spotva" wordmark.

**Status:** superseded. After seeing this artwork in place, the brand
owner found it unconvincing and asked for a new symbol built from
Spotva's own initial ("S") instead — see
`docs/SPOTVA_BRAND_IDENTITY_GUIDELINES_V1.md` §10 for the current
approved mark and the reasoning trail.

Kept here for the record only, the same way the brief's Concept B
("The Open Corner") was kept after not being selected. Do not reuse
these files in new work — the current mark lives in
`docs/brand/assets/` (not this `archive/` subfolder).
